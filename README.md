# GLP-1 Access Predictor

A machine learning project exploring GLP-1 medication access and utilization using real public health data.

## Project Goals

- Analyze real-world GLP-1 medication access and use
- Identify factors associated with GLP-1 utilization
- Develop and evaluate machine learning models
- Build an interactive prediction tool
- Explore differences in GLP-1 access across populations and states

## Data Sources

This project will use publicly available health data from sources such as the CDC and CMS.

## Project Structure

- `data/raw/` — original downloaded datasets
- `data/processed/` — cleaned datasets used for analysis
- `models/` — trained machine learning models
- `notebooks/` — exploratory analysis and experiments
- `src/` — reusable Python code
